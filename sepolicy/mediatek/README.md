# MediaTek Android 10 SELinux policy baseline

Imported from the official AOSP `device/mediatek/wembley-sepolicy` repository at
commit `92c01397c4684e597bbc0e52195825f74ef3b1cd`.

The `non_plat`, `plat_public`, and `plat_private` policy directories provide the
Android 10 policy definitions used by the legacy MediaTek services shipped on
the MT6757 platform. The upstream `MTK_LICENSE` file is retained alongside the
policy.
